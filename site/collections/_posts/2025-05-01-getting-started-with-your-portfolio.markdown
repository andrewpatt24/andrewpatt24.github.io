This is an example write-up. Duplicate this file to add new articles.

## Write-ups (blog posts)

Create a new file in `site/collections/_posts/` with front matter like:

```yaml
tags:
  - ai
  - ml
```

Tags appear in the filter bar on the Writing page and link to filtered views.

## Projects (GitHub repos)

Add entries in `site/collections/_projects/` with `github_url` and `tags` to showcase repositories with client-side filtering on the Projects page.
